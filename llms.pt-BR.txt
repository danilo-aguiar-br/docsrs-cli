# docsrs-cli
> CLI one-shot stdin/stdout para documentação do crates.io e docs.rs para agentes LLM.

docsrs-cli é um binário born-execute-finalize-die que busca crates, busca overviews README e itens rustdoc tipados, e emite envelopes JSON estáveis no stdout com diagnósticos apenas no stderr. A linha atual de release é 1.3.x (release 1.3.0) com method fail-closed (`#method.X` ausente → `not_found` exit 66), envelopes de erro com `command`+`duration_ms`, budget acima do hard max fail-closed (exit 65), match modes `--match`, eco de `--page-token` pela URL efetiva, `--suggest` em cascata (leaves de method na página pai), normalização de hífen em path, scrub de chrome rustdoc, paridade de `ok` no doctor, timeout 0 fail-closed, `schema --cmd all` (20 nomes wire) e `data.cache_hit`.

## Superfície de Comandos
- Dados: `search-crates`, `readme`, `get-item`, `search-in-crate`
- Descoberta: `version`, `doctor`, `commands`, `schema`, `completions`
- Armazenamento: `cache path`, `cache stats`, `cache clear`
- Configuração: `config path`, `config show`, `config init`
- Onze comandos de topo, dezessete caminhos invocáveis contando subcomandos

## Redução de Payload
- Oito flags globais cortam o envelope JSON antes da escrita, dispensando etapa jq
- `--select CHAVES` projeta chaves pontilhadas (alias `--fields`); chave ausente é pulada, nunca null
- `--filter EXPR` mantém elementos com `chave=valor`, `chave!=valor`, `chave~substring`; repita para AND
- `--sort-by CHAVE` ordena ascendente; elementos sem a chave vão para o fim
- `--dedupe-by CHAVE` descarta elementos posteriores que repetem o valor
- `--max-items N` limita a EMISSÃO; `search-in-crate --limit` limita a consulta
- `--count-only` substitui o payload por `{"count": N}`
- `--truncate-content N` encurta strings acima de N caracteres, sem partir UTF-8
- `--max-output-bytes N` limita o payload emitido; máximo duro 2097152
- Ordem fixa: filter, sort-by, dedupe-by, max-items, select, count-only, truncate-content, max-output-bytes
- Leia `agent_surface` para `input_count`, `output_count`, `limited`, `content_truncated`, `output_truncated`
