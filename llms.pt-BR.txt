# docsrs-cli

> CLI one-shot stdin/stdout para documentação do crates.io e docs.rs para agentes LLM.

docsrs-cli é um binário born-execute-finalize-die que busca crates, busca overviews README e itens rustdoc tipados, e emite envelopes JSON estáveis no stdout com diagnósticos apenas no stderr.
