# docsrs-cli
> CLI one-shot stdin/stdout para documentação do crates.io e docs.rs para agentes LLM.

docsrs-cli é um binário born-execute-finalize-die que busca crates, busca overviews README e itens rustdoc tipados, e emite envelopes JSON estáveis no stdout com diagnósticos apenas no stderr. A linha atual de release é 0.1.x com match modes `--match`, eco de `--page-token` pela URL efetiva, `extraction` de método, `kind=budget` não retryable, `--suggest` em cascata, normalização de hífen em path, scrub de chrome rustdoc, paridade de `ok` no doctor, timeout 0 fail-closed e `data.cache_hit`.
