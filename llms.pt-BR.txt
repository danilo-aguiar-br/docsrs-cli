# docsrs-cli
> CLI one-shot stdin/stdout para documentação do crates.io e docs.rs para agentes LLM.

docsrs-cli é um binário born-execute-finalize-die que busca crates, busca overviews README e itens rustdoc tipados, e emite envelopes JSON estáveis no stdout com diagnósticos apenas no stderr. A linha atual de release é 1.2.x (release 1.2.0) com method fail-closed (`#method.X` ausente → `not_found` exit 66), envelopes de erro com `command`+`duration_ms`, budget acima do hard max fail-closed (exit 65), match modes `--match`, eco de `--page-token` pela URL efetiva, `--suggest` em cascata (leaves de method na página pai), normalização de hífen em path, scrub de chrome rustdoc, paridade de `ok` no doctor, timeout 0 fail-closed, `schema --cmd all` (19 nomes wire) e `data.cache_hit`.
